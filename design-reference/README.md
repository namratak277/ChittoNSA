# Design reference — Chhito! mockups

One file per approved screen. These are design mockups in a custom format (they load a `support.js` runtime that is not included), so they will not open as working pages. Read them as reference:

- Layout, sizes and copy: the inline `style="..."` attributes and text.
- Drawings: copy the inline `<svg>` blocks (mountain, prayer flags, signposts, climbers, logo) into React components.
- Interactions: each file's `<script type="text/x-dc">` block shows the intended behaviour (e.g. supply budget, buzzer puzzle order, voting plan form).

Host (projector, 1280×720): Main, Host-Supplies, Mountain, Host-Reveal, Host-Buzzer, Host-Storm, Host-Summit, Host-Pledge
Player (phone, 390×844): C-Phone, Phone-Supplies, Ans-Sign-Phone, Phone-Buzzer, Phone-Summit, Phone-Pledge
Maker (laptop): Maker-SignIn, Maker-Dashboard, Maker-Builder, Maker-Host
Overviews: Story, Flow, Modes, Player-Markers, Brand-4
